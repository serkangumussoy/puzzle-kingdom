# Puzzle Kingdom GitHub Pages

## Publish
1. Create a public GitHub repository named `puzzle-kingdom` under `serkangumussoy`.
2. Upload all files and folders in this package to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Wait for the Pages deployment to finish.

Expected URLs:
- Home: https://serkangumussoy.github.io/puzzle-kingdom/
- Privacy: https://serkangumussoy.github.io/puzzle-kingdom/privacy/
- Account deletion: https://serkangumussoy.github.io/puzzle-kingdom/delete-account/
